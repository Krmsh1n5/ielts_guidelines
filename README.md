# IELTS Notes

Personal, non-commercial study notes for IELTS Academic preparation — a self-contained reference covering Reading, Listening, Speaking, and Writing, along with supporting materials (evaluator prompts, a speaking phrase bank, and a speaking question bank).

This repository exists purely as a personal study aid, shared publicly for convenience. It is **not affiliated with, endorsed by, or sponsored by** IELTS, the British Council, IDP: IELTS Australia, or Cambridge English.

---

## Purpose

These are one person's working notes, assembled while preparing for the test — not a commercial product, course, or official resource.
